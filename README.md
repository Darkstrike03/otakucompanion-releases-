# Otaku's Library Companion

**Otaku's Library Companion** is the official companion app for **[Otaku's Library](https://otakuslibrary.com)** — a platform for discovering, tracking, and curating anime, manga, manhwa, manhua, donghua, webcomics, and webnovels in one place.

The companion app brings the Otaku's Library experience to Android and adds dedicated tools for making content tracking faster and more convenient.

This repository is the **public release repository** for the companion app. It is used to distribute builds, release notes, and project information.

> **Note:** The full source code for the app is currently kept in a private repository. This public repository exists primarily for app releases. Parts of the frontend may be open-sourced later.

---

## About the App

Otaku's Library Companion extends the Otaku's Library experience beyond the website with a dedicated Flutter application.

The app is designed around a simple goal:

> **Make tracking what you watch and read as effortless as possible.**

Alongside browsing, personal libraries, and community features, the app provides dedicated tracking utilities such as the **System Overlay** and **Remind Me**.

The app currently supports content across **7 categories**:

- Anime
- Manga
- Manhwa
- Manhua
- Donghua
- Webcomics
- Webnovels

## ⚡ System Overlay

### Update your progress without leaving what you're doing.

The **System Overlay** provides a floating tracking button that can be accessed while using other apps or websites on your Android device.

Once enabled:

1. A floating Otaku's Library button appears over other apps.
2. Tap the button whenever you finish an episode or chapter.
3. Update your progress without opening the Otaku's Library app.

This is especially useful when watching anime or reading manga on another website or application.

> **Note:** The System Overlay requires Android permission to display over other applications.

---

## 🔔 Remind Me

Never forget to check back on an ongoing series.

The **Remind Me** feature allows you to set a progress range for a title.

For example:

> Remind me when this manga reaches **Chapter 120–125**.

or

> Remind me when this anime reaches **Episode 24–26**.

Once the content reaches the selected range, the app can remind you to check it.

This is useful for ongoing anime, manga, manhwa, webnovels, and other regularly updated content.
